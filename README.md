# agenticPPT

This repository contains the code, dataset labels, and experimental results for our paper. The code is organized into three main components: our custom PPTAgent implementation, the evaluation framework for testing Codex, and the dataset construction pipeline. The binary artifacts for the dataset will be uploaded shortly.

- Code for testing Codex: https://anonymous.4open.science/r/CodexPPT-codex-test/
- PPTAgent implementation: https://anonymous.4open.science/r/AgenticPPT-homemade-agent
- Dataset Builder: https://anonymous.4open.science/r/CodexPPT-dataset
- The Dataset Metadata and experimental results are included in this repo
